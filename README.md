# 净启（JingQi Guard）

> 一键净化，少些打扰。

净启是一款开源的 Android 广告治理工具，面向小米澎湃 OS 做重点适配。它组合本地 DNS/VPN 过滤、安全约束的开屏跳过规则，以及需要用户明确授权的专家系统治理能力。

净启是独立第三方项目，与小米集团及被治理应用的开发者无隶属、授权或合作关系。

## 当前版本

- 应用版本：`0.9.9`（versionCode 21）
- 正式包名：`app.jingqi.guard`
- 最低 Android：Android 9（API 28）
- 编译 SDK：Android 15 / API 35
- 重点实机：Redmi K90 Pro Max / 小米澎湃 OS 3
- 当前测试 APK ABI：`arm64-v8a`（覆盖现代 Redmi/小米设备）

`0.9.x` 已内置 Android 11+ 无线调试配对，不再要求用户安装 Shizuku。首次使用专家治理时，用户必须先从 Android 系统无障碍页明确开启“净启·开屏守护”，再在开发者选项中主动开启无线调试并打开六位配对码窗口。用户保持该系统窗口在前台，净启只在本次主动配对期间从 `com.android.settings` 的配对上下文读取一次六位码并立即本机提交；等待超过五分钟会自动取消。Android 不允许普通应用静默完成这些系统授权步骤。

## 免费版

- 本地 DNS/VPN 广告域名过滤；
- 保守的内置广告域名规则；
- 自定义域名规则；
- 应用 VPN 白名单；
- 微信、京东和金融支付应用的默认兼容保护；
- 普通开屏广告控件识别；
- 针对澎湃 OS 静默开屏的轻量前台包名检测；
- 美柚、铁路 12306 等已验证规则；
- 本地拦截统计；
- GitHub 漏网广告反馈入口。

免费版不要求 Root、无线调试、Shizuku、登录或付费。

## 专家版

Debug 和 `preview` 构建默认显示“专家内测”，便于开源贡献者和测试设备验证功能。`preview` 使用调试证书签名但按 Release 方式裁剪，适合当前实机内测。Release 构建在签名授权服务完成前保持免费版状态，不包含隐藏的本地解锁开关。

专家能力包括：

- 澎湃 OS 系统广告白名单治理；
- 当前用户范围内治理 MSA，保留系统分区原包；
- 浏览器推荐、系统预下载、预下载任务和米享广告设置治理；
- 治理前快照和逐项恢复；
- 携程、爱奇艺、小米音乐等 Canvas/视频开屏的局部视觉规则；
- 内置无线调试六位码配对和重连；
- 规划中的签名规则更新。

### 首次专家配对

1. 在系统无障碍页由你手动开启“净启·开屏守护”；
2. 建议允许净启显示通知；通知仅用于配对状态、VPN 状态和定期复查，不用于营销；
3. 在专家页点“开始一次本机配对”；
4. 在系统开发者选项进入“无线调试”；
5. 点“使用配对码配对设备”，保持系统显示六位码的窗口在前台，不要切换回净启；
6. 净启识别到该系统配对窗口后会立即在本机提交，配对和治理完成后可以关闭无线调试。

配对使用 Android 11+ 的 ADB TLS/SPAKE2 协议。六位码只在用户主动开始配对后的五分钟窗口内识别，并且同时要求系统设置包、无线调试配对文案和唯一六位数字；不会从短信、第三方应用或其他设置页面提取数字。净启只接受由本机网络接口发布的 ADB mDNS 端点；配对私钥由 Android Keystore 加密，并存放在禁止系统备份的应用私有目录中。卸载净启会删除该私钥，之后需要重新配对。

## 一键净化

首页“一键净化”会启动当前已经获得用户授权的能力：

1. 请求或复用 Android VPN 授权；
2. 启动本地 DNS 过滤；
3. 检查开屏守护状态；
4. 专家权限已经连接时，执行白名单系统治理；
5. 报告尚需用户完成的授权步骤。

Android 不允许普通应用静默开启无障碍、开发者模式或无线调试。净启只会打开相应系统页面并解释用途，最终开关由用户控制。

专家配对只治理 MSA 和澎湃 OS 系统推荐，不会代替“开屏守护”授权。酷狗、美团等文字跳过控件和携程、爱奇艺的局部视觉规则只有在用户从系统无障碍页面明确开启净启开屏守护后才会运行。

## 安全边界

- 内置 ADB 层不接受 UI、规则、反馈或网络提供的 Shell 文本，只接受编译进 APK 的类型化操作；
- 系统治理只能处理固定包和固定设置 ID，值必须通过白名单校验；
- 服务端规则不能包含 Shell、DEX、SO 或其他可执行代码；
- 携程、爱奇艺和小米音乐的视觉匹配使用 Android 官方无障碍截图 API，并在无障碍服务进程内完成；
- 屏幕图像只在内存短暂存在，不跨进程、不写入文件、不上传网络；
- 无线调试配对码只在用户主动发起配对期间、仅从 Android 系统设置的明确配对窗口读取并本机提交，不保存、不记录、不上传；
- 净启不通过特权命令启用自己的无障碍服务；
- 金融、支付、证券、钱包和保险应用使用严格规则或完全排除；
- 不安装根证书，不进行 HTTPS 中间人解密；
- DNS 命中记录只保存在本机；
- DNS 上游使用系统物理网络的多个解析服务器，支持快速失败与 UDP 截断后的 TCP 回退；
- 所有系统治理操作在首次执行前保存快照，并在执行后回读验证。

详细设计见 [安全架构](docs/SECURITY_ARCHITECTURE.md) 和 [规则格式](docs/RULE_FORMAT.md)。

## 已实机验证规则

- 携程旅行 `8.95.2`：有广告时局部视觉匹配后跳过，无广告时不点击首页；
- 爱奇艺 `17.8.0`：在同一次应用启动的短窗口内多次检查，兼容已观察到的浅色和深色开屏素材；
- 小米音乐 `4.44.0.9`：兼容“倒计时 + 跳过”节点和 QQ 音乐轻量版 Canvas 开屏；
- 深圳航空 `7.4.1`：兼容开屏阶段不发送无障碍事件的情况，并只点击已验证的 `com.air.sz:id/count_down` 控件；
- 美柚、铁路 12306：专用控件规则；
- 网易云音乐：通用文字规则；
- 招商银行、邮储银行：金融严格匹配，不使用视觉坐标盲点；
- 支付宝、云闪付、小米钱包：默认阻止自动点击。

应用升级、分辨率变化或界面调整可能使专用规则失效。规则失效应当停止自动点击并重新测试，不能扩大点击范围来追求表面命中率。

## 构建

项目要求 JDK 17 和 Android SDK 35。可以使用 Android Studio，也可以直接运行 Gradle Wrapper：

```powershell
$env:JAVA_HOME = "C:\Program Files\Android\Android Studio\jbr"
.\gradlew.bat lintDebug testDebugUnitTest assemblePreview assembleRelease
```

生成的专家内测 APK：

```text
app/build/outputs/apk/preview/app-preview.apk
```

Preview APK 使用 Android 默认调试签名，仅用于开发测试。面向网站发布前必须建立独立的长期 Release 签名，并确保私钥不进入 Git 仓库。

## 项目结构

```text
app/src/main/java/app/jingqi/guard/
├── accessibility/  # 开屏守护与金融安全策略
├── data/           # 本地状态和免费/专家权益状态
├── rules/          # 声明式应用规则模型
├── system/         # 白名单专家治理与内置 ADB 配对
├── vpn/            # 本地 DNS/VPN 过滤
├── work/           # 定期复查提醒
└── MainActivity.kt # 一键净化、权限中心和产品界面
```

## 反馈漏网广告

应用内“规则 → 提交漏网广告”会打开 GitHub Issue，并自动填入净启版本、设备型号和 Android 版本。它不会自动上传：

- 全部安装应用列表；
- DNS 查询历史；
- 无障碍控件树；
- 屏幕截图；
- 账号、余额、短信或支付信息。

金融应用反馈请只提供应用名称、版本和文字描述，不要提交包含个人信息的截图。

## 限制

没有一种技术能保证移除所有广告。与正常内容同域、离线内置、会员推广、信息流原生广告、服务端动态下发界面和应用自身业务内容，通常无法仅靠 DNS 或开屏规则处理。净启不修改第三方 APK，不注入目标进程，不绕过付费会员，不解密 HTTPS。
