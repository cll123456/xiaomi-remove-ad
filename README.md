# 澎湃净广（HyperAdGuard）

一个面向小米澎湃 OS 的本地广告治理工具。当前版本为 `0.6.1`，主要在 Redmi K90 Pro Max / 澎湃 OS 3 上开发和实机验证。

## 功能

- 本地 DNS/VPN 广告域名过滤，不上传 DNS 查询或访问日志；
- 内置广告域名规则、自定义规则和应用绕过名单；
- 实时拦截计数与最近命中记录；
- 通过 Shizuku 执行经过硬编码约束的澎湃 OS 广告治理命令；
- 一键移除当前用户的 MSA、关闭浏览器推荐和系统预下载设置；
- 通过无障碍服务自动点击普通第三方应用中可识别的“跳过广告”按钮；
- 对携程旅行和爱奇艺的 Canvas/视频开屏广告提供专用视觉识别规则；
- 银行、支付、证券、钱包和保险应用默认进入严格保护模式，不执行坐标盲点；
- 支持单独停用开屏自动跳过，不影响 DNS/VPN 和系统治理结果；
- 开机恢复与每周复查提醒。

## 构建

项目要求 JDK 17、Android SDK 35，最低支持 Android 9（API 28）。可以使用 Android Studio 打开项目，也可以直接运行 Gradle Wrapper：

```powershell
$env:JAVA_HOME = "C:\Program Files\Android\Android Studio\jbr"
.\gradlew.bat testDebugUnitTest assembleDebug
```

生成的调试 APK 位于：

```text
app/build/outputs/apk/debug/app-debug.apk
```

## 权限与首次设置

1. 启动本地 VPN 并允许系统的 VPN 连接请求；
2. 安装并启动 Shizuku，向澎湃净广授予 Shizuku 权限；
3. 启用“开屏广告自动跳过”无障碍服务；
4. 在应用中执行一次“一键治理”。

Shizuku 用于修改当前用户的系统广告设置，以及为 Canvas 开屏广告提供只读屏幕帧。项目不需要 Root。

## 工作原理

### DNS/VPN 过滤

应用建立本地 VPN，仅处理虚拟 DNS 地址上的 DNS 数据包。命中本地域名规则的请求返回 NXDOMAIN，其他请求转发给系统当前使用的 DNS。应用不安装根证书、不解密 HTTPS，也不修改其他应用的数据。

### 系统治理

通过 Shizuku 用户服务执行项目内预先定义的命令，移除当前用户的 MSA 包并修改已知的澎湃 OS 广告设置。系统分区里的原始 APK 不会被删除；恢复操作可以重新安装系统预置包并还原治理前快照。

### 开屏自动跳过

普通应用优先通过无障碍节点中的文本、资源 ID 和可点击父节点识别“跳过”按钮。金融类应用只允许严格的文字与资源 ID 匹配，并排除支付宝、银联、小米钱包等敏感包。

携程和爱奇艺的开屏按钮绘制在 Canvas/视频层中，不会出现在无障碍控件树。针对这两个包，Shizuku 特权进程会获取当前屏幕、在内存中缩小为低质量 JPEG，并只检测右上角的小区域。命中特征后才发送点击手势；画面不会写入文件或上传网络。规则基于具体应用版本和界面布局，应用升级后可能需要重新校准。

## 已实机验证

- 携程旅行 `8.95.2`：有广告时自动跳过，无广告时不点击首页按钮；
- 爱奇艺 `17.8.0`：兼容已观察到的浅色和深色轮换开屏素材；
- 美柚、铁路 12306：专用跳过模式；
- 网易云音乐：通用文字规则；
- 招商银行、邮储银行：严格匹配模式，不使用坐标点击。

## 安全边界

- 所有规则、统计和命中记录只保存在设备本地；
- 不保存或上传携程、爱奇艺的检测画面；
- 不进行 HTTPS 中间人解密；
- 不读取账户密码、短信、支付内容或银行卡信息；
- Shizuku 服务只暴露项目内使用的受限接口；
- 银行和支付类应用不使用视觉坐标盲点；
- 可以在应用中单独停用开屏自动跳过，或停止 VPN 恢复原网络行为。

## 限制

任何单一方式都不能保证移除所有广告。与正常内容同域、离线内置、会员推广、信息流原生广告以及服务端动态下发的界面，通常无法仅靠 DNS 过滤。专用视觉规则也可能因应用版本、分辨率或布局变化而失效，需要针对新版本更新。
