# 安全架构

## 信任边界

净启包含三个权限层级：

1. 普通应用进程：界面、本地规则、状态和反馈入口。
2. Android VPN/无障碍服务：仅在用户通过系统界面授权后运行。
3. 专家 Shell 服务：仅在用户完成 Shizuku 或未来的内置无线调试配对后运行。

任何网络服务、规则文件或反馈内容都不属于可信执行主体。

## 特权接口

`IPrivilegedService` 只暴露以下类型化能力：

- 查询固定包是否存在；
- 对固定包执行当前用户移除或恢复；
- 读取固定系统设置；
- 将固定系统设置写入严格验证后的值；
- 对固定视觉模板执行屏幕内匹配；
- 销毁本地 Shell 服务。

接口不暴露命令字符串、文件路径、包名、系统设置键或视觉区域坐标。规则只能引用编译进应用的整数 ID。

## 屏幕数据

携程和爱奇艺等应用可能把跳过按钮绘制在 Canvas/视频层，无法从无障碍节点树读取。专家 Shell 服务可以临时调用系统 `screencap`：

1. PNG 只存在于 Shell 进程内存；
2. 只计算编译时固定区域的像素特征；
3. 立即回收 Bitmap；
4. 只向无障碍服务返回布尔值；
5. 不写磁盘、不加入日志、不上传网络。

金融、支付、钱包、证券和保险应用不使用该能力。

## 系统治理与恢复

首次治理前保存：

- MSA 在当前用户中的安装状态；
- 浏览器推荐设置；
- 系统云预下载设置；
- 预下载任务列表；
- 米享广告设置；
- 快照格式版本和创建时间。

治理后逐项回读。恢复完成且所有项目验证成功后才删除快照。新版本无法理解旧快照时不得猜测恢复值。

## 远程规则

规划中的规则包采用 Ed25519 离线签名，并包含模式版本、规则修订号、最低客户端版本、生成时间和签名。客户端必须防止版本回滚。

规则包禁止包含：

- Shell 命令；
- Intent URI；
- 文件路径；
- JavaScript；
- DEX、JAR、APK 或原生库；
- 任意系统设置键；
- 任意坐标点击规则；
- 金融应用视觉截图规则。

## 密钥

- APK Release 私钥离线保存，不进入源码或 CI 普通日志；
- 规则签名密钥与 APK 签名密钥分离；
- 授权签名密钥与规则签名密钥分离；
- 无线调试客户端私钥存放于 Android Keystore；
- 生产支付密钥和数据库凭证永不进入开源仓库。

## 已知剩余工作

- 用内置 ADB TLS 配对替换 0.8.x 的外部 Shizuku 启动路径；
- 为规则包实现规范化编码、签名校验和防回滚；
- 为正式授权实现服务端签名凭证；
- 对导出的诊断日志做字段级脱敏；
- 增加 Android 组件导出和依赖漏洞的持续检查。
