# 净启产品定义

## 定位

净启是一个“本地优先、明确授权、可撤销”的 Android 广告治理工具。它不承诺移除所有广告，也不以获取尽可能多的系统权限为目标。

- 正式名称：净启
- 完整描述：净启——安卓广告治理助手
- 英文名称：JingQi Guard
- 包名：`app.jingqi.guard`
- 宣传语：一键净化，少些打扰。

## 产品原则

1. 免费版本地功能可以独立使用，不以账号或付费墙阻断基础保护。
2. 专家版采用低价买断，不做自动续费。
3. Android 客户端、规则引擎和未来服务端全部开源。
4. 付费价值来自官方签名构建、持续规则、自动适配、设备授权和支持，而不是隐藏代码。
5. 敏感权限逐项说明、逐项授权、逐项撤销。
6. 金融应用宁可漏过广告，也不允许坐标盲点和宽松识别。
7. 系统治理必须有治理前快照、逐项结果和恢复路径。
8. 规则更新只能更新数据，不能下载执行代码或 Shell 命令。

## 版本边界

### 免费版

- 本地 DNS/VPN；
- 自定义域名规则；
- 应用 VPN 白名单；
- 普通无障碍开屏规则；
- 基础规则更新；
- 本地统计；
- 漏网广告反馈。

### 专家版

- 内置无线调试配对；
- 澎湃 OS 白名单系统治理；
- 局部视觉开屏规则；
- 定期系统复查；
- 签名完整规则包；
- 设置快照和恢复；
- 最多三台设备和自助解绑；
- 优先反馈处理。

## 商业约定

专家版为一次买断。购买后永久保留已经交付的本地专家功能；在线规则、反馈处理和授权恢复在项目正常运营期间提供。客户端必须支持合理的离线使用，不以短周期强制联网惩罚已购买用户。

若项目停止在线服务，应尽力发布可验证的最终离线版本或公开迁移说明。

## 非目标

- 不修改或重打包第三方 APK；
- 不注入第三方应用进程；
- 不绕过付费会员权益；
- 不安装 HTTPS 根证书；
- 不收集完整浏览记录；
- 不远程控制设备；
- 不承诺所有品牌、所有 Android 版本都可用；
- 不伪装成小米或任何第三方应用的官方工具。
